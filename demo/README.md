# AgentVendi Demos

This folder contains example agent configurations that you can import into your AgentVendi instance.

## How to use:
1. Open the AgentVendi dashboard.
2. Go to "Import Agent".
3. Drag and drop any of the `.json` files in this directory.

## Included Examples:
- `code_sentinel.json`: A strict code reviewer.
- `api_architect.json`: Specialist for designing REST/GraphQL APIs.
- `k8s_manager.json`: Helps with Kubernetes manifests and monitoring.
